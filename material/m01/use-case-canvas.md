# Use-Case-Canvas: Arbeitsblatt für den eigenen Anwendungsfall

Kursmaterial „Working with GenAI", Modul 1, Lektion 1.3. Dieses Arbeitsblatt bereitet **Portfolio-Teil 1** vor. Die sechs Felder sind dieselben wie in der [Portfolio-Vorlage](../portfolio-vorlage.md); die Kriterienprüfung davor hilft bei der Auswahl. Ausgefüllt wird mit Stichworten, nicht mit ausformulierten Absätzen.

> **Datenregel:** Keine echten Namen, Adressen, Kunden- oder Vertragsnummern. Der eigene Fall wird so beschrieben, dass niemand daraus eine reale Person oder ein vertrauliches Detail erkennen kann.

---

## Schritt 1: Zwei bis drei Kandidaten sammeln

Wiederkehrende Schreib- oder Prüfanlässe aus dem eigenen Arbeitsalltag, je ein Satz:

- Kandidat 1: <…>
- Kandidat 2: <…>
- Kandidat 3: <…>

## Schritt 2: Kriterienprüfung

| Kriterium | Kandidat 1 | Kandidat 2 | Kandidat 3 |
|---|---|---|---|
| Wiederkehrend | ja / teils / nein | | |
| Feste Fakten liegen freigegeben vor | | | |
| Ergebnis ist Aussage für Aussage prüfbar | | | |
| Eine Person liest und verantwortet den Entwurf | | | |
| Keine personenbezogenen Daten, keine offene Rechtsfrage | | | |

Gewählt wird der Kandidat mit den meisten **ja**. Ein **nein** bei „Feste Fakten" oder „Prüfbar" spricht gegen einen Start. Ein **nein** bei der letzten Zeile heißt: zuerst klären.

**Gewählter Fall:** <…>

**Warum dieser und nicht die anderen:** <ein Satz>

## Schritt 3: Der erste Canvas-Eintrag

| Feld | Eintrag |
|---|---|
| **Problem** | <Welche Aufgabe kostet heute Zeit oder Qualität? Was passiert, wenn sie schlecht läuft?> |
| **Zielgruppe** | <Wer bekommt das Ergebnis?> |
| **Nutzenversprechen** | <Was ist danach besser? Größenordnung, falls bekannt: Minuten pro Vorgang, Vorgänge pro Woche> |
| **Häufigkeit und Umfang** | <Wie oft, wie lang ein Vorgang?> |
| **Datenbedarf** | <Welche Angaben braucht eine korrekte Antwort? Wo liegen sie heute? Sind sie freigegeben?> |
| **Abgrenzung** | <Was gehört ausdrücklich nicht dazu? Welche Entscheidung bleibt bei einem Menschen?> |

## Schritt 4: Was noch fehlt

Zwei Rückfragen, die vor dem ersten Arbeitsauftrag beantwortet sein müssen (etwa: Wo genau liegen die Fakten? Wer gibt sie frei?):

1. <…>
2. <…>

---

Der ausgefüllte Canvas wird in die Arbeitsmappe kopiert (Portfolio-Teil 1). Freitexte werden im Kurs nicht automatisch bewertet; die Rückmeldung kommt im Beratungstermin.
