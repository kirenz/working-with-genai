# Use-Case-Canvas: Arbeitsblatt für den Pilotfall

Kursmaterial „Working with GenAI", Modul 1, Lektion 1.9 „Den Pilotfall im Use-Case-Canvas festhalten". Dieses Arbeitsblatt bereitet **Portfolio-Teil 1** vor. Die sechs Felder sind dieselben wie in der [Portfolio-Vorlage](../portfolio-vorlage.md). Arbeitsgrundlage sind die Kandidatenliste aus dem Tätigkeitsinventar (Lektion 1.7) und der Kandidatenvergleich (Lektion 1.8); beide bleiben in der Arbeitsmappe. Ausgefüllt wird mit Stichworten, nicht mit ausformulierten Absätzen.

> **Datenregel:** Keine echten Namen, Adressen, Kunden- oder Vertragsnummern. Der eigene Fall wird so beschrieben, dass niemand daraus eine reale Person oder ein vertrauliches Detail erkennen kann.

---

## Schritt 1: Den Pilot zuschneiden

Der erste Kandidat aus dem Vergleich wird auf einen Ausschnitt mit passender Informationsgrundlage und Prüfmaßstab zugeschnitten. Für Auskünfte sind das etwa freigegebene Fakten; für Ideen Ziele, Rahmenbedingungen und Kriterien.

**Gewählter Ausschnitt:** <…>

**Warum dieser und nicht der ganze Vorgang oder ein anderer Kandidat:** <ein Satz>

| Was festgehalten wird | Eintrag |
|---|---|
| **Der heutige Ablauf** | <Wer tut was in welcher Reihenfolge; Dauer je Vorgang als Beobachtung oder Annahme> |
| **Ein beobachtbares Erfolgskriterium** | <Minuten je Vorgang einschließlich Vorbereitung, Prüfung und Nacharbeit; Rückfragen je Woche; Vollständigkeit einer Übergabe oder brauchbare, unterscheidbare Ideen anhand vereinbarter Kriterien. Heutiger Wert, nach vier Wochen erneut zu beobachten> |
| **Was das Modell übernimmt, was bleibt** | <Welcher Schritt wird unterstützt; wer prüft; welche Entscheidung bleibt bei einer Person> |

## Schritt 2: Die fünf Pilotkriterien

| Kriterium | ja / teils / nein | Bemerkung |
|---|---|---|
| Wiederkehrend | | |
| Passende Informationsgrundlage: Fakten oder Ziele, Rahmenbedingungen und Kriterien | | |
| Prüfbares Ergebnis mit klarem Maßstab | | |
| Eine Person liest und verantwortet das Ergebnis | | |
| Material und Werkzeug für den erfundenen Übungsfall nutzbar | | |

Fehlen nötige Fakten, Ziele oder Kriterien, werden diese ergänzt oder der Ausschnitt angepasst. Ideen und Einschätzungen brauchen keine festen Fakten als Ausgangspunkt; Brauchbarkeit und Vielfalt benötigen dennoch einen Maßstab. Für die Übung wird ein vollständig erfundener Fall verwendet. Offene Fragen zur realen Anwendung werden als Rückfragen notiert.

## Schritt 3: Der Canvas-Eintrag

| Feld | Eintrag |
|---|---|
| **Problem** | <Welcher Vorgang und welcher Schritt darin kostet heute Zeit oder Qualität? Wie läuft es heute? Was passiert, wenn es schlecht läuft?> |
| **Zielgruppe** | <Wer bekommt das Ergebnis?> |
| **Nutzenversprechen (Annahme)** | <Das beobachtbare Erfolgskriterium aus Schritt 1, heutiger Wert als Beobachtung oder Annahme gekennzeichnet> |
| **Häufigkeit und Umfang** | <Wie oft, wie lang ein Vorgang?> |
| **Datenbedarf** | <Welche Angaben braucht das Ergebnis? Wo liegen sie heute? Welche Kategorie (A, B, C)?> |
| **Abgrenzung** | <Was übernimmt das Modell, was bleibt bei einem Menschen? Welche Aussage geht nie ohne Prüfung hinaus?> |

## Schritt 4: Was noch fehlt

Zwei Rückfragen, die vor dem ersten Arbeitsauftrag im eigenen Haus beantwortet sein müssen (etwa: Wo genau liegen die Fakten? Wer gibt sie frei? Wer entscheidet über das Konto?):

1. <…>
2. <…>
