# Produkttext prüfen: Espresso Intenso

Kursmaterial „Working with GenAI", Modul 1, Lektion 1.2. Synthetische GenAI-Erweiterung des Lehrfalls Rösterei Morgenrot. Der Text unten ist **konstruiert**, kein aufgezeichneter Modelloutput. Er zeigt, wie ein flüssiger Produkttext aussehen kann, wenn ein Chatmodell nur den Satz „Schreibe einen Produkttext für unseren Espresso Intenso" bekommt und kein Material.

Grundlage für die Prüfung ist ausschließlich das [freigegebene Briefing](briefing-abo-hinweistext.txt).

## Der Entwurf

> **Espresso Intenso: kräftig, rund, unverwechselbar**
>
> Unser Espresso Intenso wird in kleinen Mengen in unserer eigenen Rösterei geröstet. (1) Die Bohnen stammen aus Hochlagen Kolumbiens und Brasiliens (2) und werden schonend im Trommelröster veredelt. (3) Das Ergebnis ist ein 100 % Arabica-Espresso (4) mit Noten von dunkler Schokolade und Karamell. (5) Espresso Intenso ist Bio-zertifiziert (6) und kostet im Onlineshop 10,00 EUR. (7) Im Kaffee-Abo erhalten Sie ihn regelmäßig nach Hause geliefert (8) und sparen dabei 10 Prozent gegenüber dem Einzelkauf. (9)

## Prüfbogen

Zu jeder nummerierten Aussage: Steht sie so im Briefing? Wenn ja, in welcher Zeile? Wenn nein, wie lautet die Konsequenz?

| Nr. | Aussage | Im Briefing gedeckt? | Fundstelle oder Konsequenz |
|---|---|---|---|
| 1 | in kleinen Mengen in eigener Rösterei geröstet | | |
| 2 | Bohnen aus Hochlagen Kolumbiens und Brasiliens | | |
| 3 | schonend im Trommelröster | | |
| 4 | 100 % Arabica | | |
| 5 | Noten von dunkler Schokolade und Karamell | | |
| 6 | Bio-zertifiziert | | |
| 7 | kostet im Onlineshop 10,00 EUR | | |
| 8 | im Abo regelmäßig nach Hause geliefert | | |
| 9 | 10 Prozent Ersparnis gegenüber dem Einzelkauf | | |

## Auflösung (erst nach dem eigenen Durchgang lesen)

| Nr. | Gedeckt? | Begründung |
|---|---|---|
| 1 | teilweise | „Kleine Kaffeerösterei" steht im Briefing. „In kleinen Mengen geröstet" ist eine Aussage über das Verfahren und steht dort nicht. Streichen oder auf „aus unserer kleinen Rösterei" zurückführen. |
| 2 | nein | Herkunftsländer sind ausdrücklich nicht freigegeben. Streichen. |
| 3 | nein | Röstverfahren ist nicht freigegeben. Streichen. |
| 4 | nein | Zur Bohnensorte liegt nichts vor. Streichen. |
| 5 | nein | Geschmacksbeschreibungen sind nicht freigegeben. Streichen. |
| 6 | nein | Zertifikate sind nicht freigegeben. Eine falsche Zertifikatsaussage wäre außerdem ein Produktversprechen mit Außenwirkung. Streichen. |
| 7 | ja | Listenpreis Espresso Intenso 10,00 EUR steht im Briefing. |
| 8 | ja | „Das Kaffee-Abo liefert regelmäßig nach Hause" und „Alle drei Sorten sind im Abo wählbar" decken die Aussage. |
| 9 | nein | Abo-Preise und Rabatte sind nicht freigegeben. Streichen. |

Ergebnis der Prüfung: Von neun Aussagen sind zwei gedeckt, eine teilweise, sechs nicht. Der Text klingt trotzdem stimmig. Genau das ist der Punkt der Lektion: Die Lesbarkeit eines Textes sagt nichts über seine Belegbarkeit.

## Was nach der Prüfung übrig bleibt

Ein belegbarer Kern in zwei Sätzen, konstruiert:

> Espresso Intenso ist eine der drei Sorten unserer kleinen Rösterei und kostet im Onlineshop regulär 10,00 EUR. Im Kaffee-Abo kommt er regelmäßig nach Hause; ein Sortenwechsel gilt für die nächste Lieferung, wenn die Anfrage spätestens fünf Werktage vor deren Versand eingeht.

Offen und für einen längeren Produkttext nachzuliefern: Herkunft, Röstung, Geschmacksbeschreibung, Zertifikate. Wer diese Angaben freigibt, ist im Fall Aylin Yılmaz.
