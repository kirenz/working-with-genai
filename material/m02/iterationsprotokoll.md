# Iterationsprotokoll: eine Änderung pro Durchlauf

Kursmaterial „Working with GenAI", Modul 2, Lektion 2.3. Das Protokoll gehört zu **Portfolio-Teil 2, Entwicklungsschritte**. Es hält fest, was verändert wurde und was danach beobachtet wurde. Es beweist keine Ursache; wenige Durchläufe reichen dafür nicht. Es macht die eigene Arbeit nachvollziehbar.

## Leere Vorlage

| Durchlauf | Was wurde geändert (genau eine Sache) | Wo (Folgeanweisung im selben Chat / neue Fassung in neuem Chat) | Beobachtung im Ergebnis | Entscheidung für den nächsten Durchlauf |
|---|---|---|---|---|
| 1 | Ausgangsfassung | neuer Chat | | |
| 1b | nichts (unveränderte Wiederholung) | neuer Chat | | |
| 2 | | | | |
| 3 | | | | |
| 4 | | | | |

**Prüfkriterien, die in jeder Zeile gleich bleiben:** Belegbarkeit jeder Aussage, Bedingung an der Zusage, offene Punkte sichtbar, keine behauptete Handlung, Format.

## Ausgefülltes Beispiel (konstruiert, Kundenanfrage 2)

Alle Beobachtungen sind konstruiert. Sie zeigen, wie Einträge aussehen, nicht, was ein Modell tun wird.

| Durchlauf | Was wurde geändert | Wo | Beobachtung im Ergebnis | Entscheidung |
|---|---|---|---|---|
| 1 | Ausgangsfassung v1: nur Kundenmail, Auftrag „freundlich im Hausstil" | neuer Chat | Entwurf wie in `durchlauf-1-entwurf.txt`: Bio-Aussage erfunden, Aussetzen ohne Bedingung zugesagt, Handlung behauptet, Anrede mit Namen | Zuerst die Belegbarkeit reparieren: Fachinformationen als Material mitgeben und die Grenze „nur Material" setzen |
| 1b | nichts | neuer Chat | Wieder unbelegte Angaben, aber andere: diesmal „Versand innerhalb von zwei Werktagen" statt der Bio-Aussage | Bestätigt: Ohne Material ist nicht vorhersagbar, welche Lücke gefüllt wird. Änderung aus Zeile 1 durchführen |
| 2 | Material und Grenzen ergänzt (Fassung v2) | neuer Chat | Keine Bio-Aussage mehr; „dazu liegt uns keine Angabe vor". Aussetzen weiterhin ohne Frist zugesagt, „wir veranlassen das" bleibt | Nächste Änderung: Bedingung und Handlungsverbot als Format-/Grenzregel aufnehmen |
| 3 | Eine Zeile ergänzt: „Eine Bedingung steht im selben Satz wie die Zusage. Behaupte keine veranlasste Handlung." (Fassung v3) | Folgeanweisung im selben Chat wie Durchlauf 2 | Frist steht im Satz, Versanddatum unter „Offen", keine Handlungsbehauptung. Anrede noch „Sehr geehrte Frau Novak", 140 Wörter | Nächste Änderung: Format (Anrede, Signatur, Längengrenze) über das Musterbeispiel aus 2.2 |
| 4 | Musterbeispiel als Format eingefügt (Fassung v4) | neuer Chat mit der vollständigen Fassung v4 | Anrede „Guten Tag,", Signatur korrekt, 96 Wörter, Liste „Offen" nach der Signatur. Alle drei Antwortlagen sichtbar unterschieden | Fassung v4 als Arbeitsstand in die Arbeitsmappe übernehmen; im nächsten Durchlauf unverändert wiederholen |

**Lesehilfe:** Zeile 3 wurde als Folgeanweisung im selben Chat gemacht. Damit die Verbesserung wiederverwendbar bleibt, wurde dieselbe Zeile anschließend in die vollständige Fassung v3 eingetragen. Eine Folgeanweisung repariert den Entwurf; die Fassung repariert den Auftrag.
